# Task-JS-Tools-WDIO-JestMocha--Chai

## Project Overview

Web automation testing framework built with WebdriverIO, Mocha, and Chai, following the Page Object Model (POM) design pattern.

The automated tests cover the Automation Test Store homepage, including:

- Search field placeholder validation.
- Men navigation element existence.
- Latest Products section visibility.

The project also demonstrates the use of Chai's three assertion interfaces: Expect, Assert, and Should.

## Tech Stack

- JavaScript
- WebdriverIO
- Mocha
- Chai
- Bun

## Installation

Install project dependencies:

```bash
bun install
```

## Run Tests

Execute the test suite:

```bash
bun run wdio
```
